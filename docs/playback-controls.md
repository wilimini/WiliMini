# 播放控制、画质与弹幕

播放按键参考 [PSP 官方说明](https://manuals.playstation.net/document/en/psp/current/video/keyassign.html)
和 [wiliwili video_view.cpp](https://github.com/xfangfang/wiliwili/blob/88e5876bea9502d06f46a8656e3530684d3aaf7d/wiliwili/source/view/video_view.cpp)，
按 PSP 操作习惯调整如下。确认键和返回键遵循客户端设置。

| 按键 | 播放中的操作 |
| --- | --- |
| START / 确认 | 暂停、继续 |
| L / R | 后退、前进 10 秒 |
| 左 / 右 | 每步调整 1 秒；长按移动预览进度，松开后合并提交跳转 |
| △ | 进入、离开底部操作栏 |
| □ | 切换弹幕显示 |
| 返回 | 关闭设置、取消进度预览；否则退出播放 |

底部操作栏依次为弹幕、字幕、画质：左右选择入口，确认展开直角半透明列表。
画质列表上下或左右预选、确认应用；字幕列表上下或左右切换，立即生效。
弹幕列表上下切换开关/密度/透明度类别，左右调整。返回键先收起列表，再离开操作栏。
提供画质、字幕轨道、弹幕开关、密度（低/中/高）、透明度（50/75/100%）。
暂停和跳转预览会保留控制栏；正常播放时自动隐藏。
全屏控制栏使用上下渐变遮罩、底部细进度条及图标，常驻按键说明不再覆盖视频。
菜单以直角半透明列表显示当前类别，粉色文字标识预选项；角落不再显示返回或设置图标。
左右预览目前只显示目标时间和进度条，不生成缩略图。

## 跳转与资源生命周期

原生 ME 后端在同一次 `psp_video_play` 调用中执行 seek，保留视频容器、
视频解码器、ME 实例、RGB 分配和下载源。跳转时暂停输出，结束旧音频工作线程，
临时中断缓存读取，等待 ME 完成，丢弃旧 RGB 帧，然后定位关键帧并刷新解码状态。
音频管线目前仍会重新打开和预缓冲；这会带来等待，不能视为无延迟跳转。
暂停时跳转会显示新位置的首帧，并保持暂停。

`PspVideoSource.interrupt_reads` 只中断当前读取，不取消下载源。
Range 下载完成后工作线程保持等待，向已淘汰区间回退时重新发起 Range 请求；
最终关闭源时必须唤醒并回收该线程。
旧的可选 sceMpeg 后端仍采用退出并重新打开的跳转回退路径。

画质切换属于更换媒体源，需要重新准备播放，但保留当前位置、暂停状态和弹幕设置。
只显示接口实际返回的 H.264 360p、480p、720p 选项，限制尺寸不超过 1280×720。
默认仍为 360p；更高分辨率可被选择不代表 PSP 能流畅播放。
菜单设置目前只在本次客户端会话保留。

## 叠加绘制

ME 继续负责视频转色和缩放，CPU 负责文字准备和弹幕排布，GE 绘制叠加层。
使用三块 512×272 RGBA 显存页：一块干净视频页、两块交替显示页。
同步 DMA 先更新干净视频页，GE 将其复制到后台页并绘制控件和弹幕，
等待 GE 完成及垂直同步后换页。暂停重绘也从干净页开始，避免文字残留。
渲染期间不从磁盘加载字体；播放前准备字形图集和弹幕纹理。

图标来自固定 wiliwili 提交，来源见 `assets/player/MANIFEST.json`，
许可证见 `client/assets/wiliwili/WILIWILI-LICENSE.txt`。
`make assets` 通过 `scripts/generate-player-icons.py` 重新生成图标头文件，
需要 rsvg-convert 和 ImageMagick；普通打包使用已生成资源。

## 弹幕范围与限制

按 cid 请求 Bilibili XML 弹幕池；失败不阻止视频播放。
响应限制 512 KiB，最多解析 4096 条，拒绝 DTD/实体声明。
仅支持普通滚动、顶部固定、底部固定，单条最多 28 个码点。
播放前按时间采样最多 96 条，纹理总量限制 768 KiB。
这是有界的轻量弹幕池，不是完整分段弹幕、历史弹幕或高级脚本弹幕实现。

低/中/高密度使用 2/4/6 条轨道。滚动弹幕统一速度，按上一条宽度加间距
控制入场；固定弹幕等待上一条结束。按媒体时钟定位，暂停时冻结，跳转时重新排布。
顶部标题和底部字幕区留出空间，字幕启用且控制栏出现时进一步压缩弹幕区域。

## 验证范围

主机控制状态和弹幕解析/排布测试使用 ASan/UBSan；RGB 队列测试覆盖 2/4/8 帧。
PPSSPP 原生 ME 控件回放覆盖暂停、时钟、进度预览、合并跳转、暂停跳转、
单实例 ME、菜单设置和画质请求；另运行 MP4/DASH/FLV 播放回归。
画质请求测试不等于真实 CDN 切流验证。
本地 HTTP Range 服务的 PPSSPP 实时回放已验证 55→45→55 秒跳转、
单次播放/单次 RGB 初始化和网络线程正常清理；同时修复向前读取超出
当前环形窗口时生产者与读者互等的问题。

真机通过 PSPLink 单独验证，不能用模拟器结果替代。
PSP-3000 本地样片测试完成 6 次同实例跳转，用户确认显示与操作正常；
退出后线程名称与数量恢复到基线的 18 个，无应用工作线程残留。
最新 Range 窗口修复只经过模拟器网络验证；真实 CDN 画质切换仍未验证。
EOF、网络缓存不足和音频重新预缓冲仍可能增加跳转等待。

## 字幕

通过 `/x/player/v2` 获取当前 bvid/aid、cid 对应的字幕轨道，下载接口返回的 HTTPS JSON。
字幕是可选资源，失败或无轨道时菜单显示“暂无可用字幕”，不阻止视频播放。
默认关闭，通过底部“字幕”选择语言；同视频切画质保留选择，换视频恢复关闭。

播放准备阶段最多尝试三条轨道，每条响应上限 512 KiB、2048 句、128 KiB 文本，
超限轨道整体跳过；字幕字形总量上限 4096，超出预算的轨道不提供选择。
字形在播放前复制到内存，播放中仅在句子变化时更新一块 512×64 T4 纹理，
不访问磁盘和网络。按当前媒体时间选择字幕，区间为起点包含、终点不包含；
暂停冻结，跳转重新查找，空白区间清除旧字幕。重叠时选择最近开始的有效句子。

字幕居中显示，白字黑描边，自动折为最多两行；超出两行的长句尾部不显示。
控制栏显示时上移，隐藏时靠近底部；不支持外部字幕文件、ASS 特效或实时语音识别。
主机测试覆盖 JSON 边界、时间间隙、倒退跳转和重叠字幕；模拟器使用固定双语轨道
验证渲染及控制。公共元数据端点探测成功，但样本没有字幕；不能据此声称已验证
真实账号视频的字幕下载或 PSP 真机字幕显示。
